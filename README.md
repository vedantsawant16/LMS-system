# 🎓 EduVerse - Learning Management System

A full-stack Learning Management System (LMS) built using Next.js, Prisma, SQL, Clerk Authentication, Stripe, UploadThing, and Mux. It enables instructors to create courses and students to enroll, watch videos, track progress, and complete lessons.

## ⚙ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/LMS-system.git
```

Go to project folder

```bash
cd LMS-system
```

Install dependencies

```bash
npm install
```

Create .env

```env
DATABASE_URL=
CLERK_SECRET_KEY=
CLERK_PUBLISHABLE_KEY=
STRIPE_SECRET_KEY=
MUX_TOKEN_ID=
MUX_TOKEN_SECRET=
UPLOADTHING_SECRET=
UPLOADTHING_APP_ID=
```

Run

```bash
npm run dev
```
